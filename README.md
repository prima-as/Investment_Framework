
# 📈 Investment Framework

A Python project for learning **Top-Down Investing** by building an interactive macroeconomic dashboard.

---

## 🎯 Project Goal

This project combines:

- Investment Education
- Macroeconomic Analysis
- Python Development
- Interactive Dashboard

into a single learning framework.
